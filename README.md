# Image Compressor – MRPS

An offline image compression utility for Android. 

This repository contains the source code for the Image Compressor app by MRPS. The app is designed to compress images entirely locally on your device without requiring internet access or uploading your data to any servers.

## Features
- **Offline Processing:** All compression happens on your phone's processor.
- **Privacy First:** No tracking, no analytics, no accounts required.
- **Customizable:** Adjust image dimensions and quality to fit your needs.

## Building the App
To build the app, clone the repository and open it in Android Studio. Please note that the release signing keystore is intentionally excluded from this repository for security reasons. To build a signed release APK, you will need to provide your own keystore or configure a new signing configuration in Android Studio.
